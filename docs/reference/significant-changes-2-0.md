# Significant Changes in SeaBlock 2.0

This page is the canonical summary of major gameplay-impacting SeaBlock 2.0 changes.

Use this as a quick orientation before starting a new 2.0 run or migrating 1.1-era expectations.

## Read this if...

- You played SeaBlock 1.1 and want to know what changed.
- A guide, video, or blueprint feels "off" in 2.0.
- You want the short list of changes that alter planning decisions.

## SeaBlock-specific 2.0 changes

| Change | What changed | Practical impact |
| --- | --- | --- |
| T1 bots and roboports available earlier | Logistics bots/roboport progression is accessible sooner. | Earlier mall recovery, easier retrofit work, faster rebuilding loops. |
| Blue algae and oil/gas flow simplification | Blue algae path no longer depends on older multiphase oil/gas complexity in the same way. | Mid-game petrochem onboarding is smoother and easier to stage. |
| Nuclear is more fleshed out | Nuclear progression has broader practical relevance and clearer integration points. | More viable late-mid to late power strategy, not just niche fallback. |
| Crushed stone recipe normalization | Crushed stone was removed from many recipe paths and replaced by stone requirements. | Old chains that produce/consume crushed stone directly may need redesign. |

## Inherited base Factorio 2.0 changes that matter in SeaBlock

| Base game 2.0 inheritance | Why it matters in SeaBlock |
| --- | --- |
| Beacon and module behavior changes | Throughput and late-game optimization assumptions from 1.1 are not directly portable. |
| Additional module ecosystem options (including agricultural modules) | More choices in specialized builds; validate balance impact before mass rollout. |
| General 2.0 logistics/QoL improvements | Early and mid-game infrastructure setup can be staged differently than older guide advice. |

## Gameplay impact by phase

### Early game

- Earlier bot access changes how soon cleanup/refactor tools become practical.
- Stone normalization can break muscle memory from crushed-stone-first layouts.

### Mid game

- Blue algae/petrochem simplification changes when fluid complexity spikes.
- Transition timing in filtration/smelting may shift from old 1.1 heuristics.

### Late game

- Beacon/module inheritance from 2.0 changes optimization strategy.
- Improved nuclear relevance affects power roadmaps and UPS planning.

## Migration impact (1.1 mindset to 2.0)

Common breakpoints when reusing old plans:

1. Stone chain assumptions still built around crushed stone.
2. Smelting and catalyst assumptions copied from old charts.
3. Power scaling order copied from 1.1 without re-checking module/beacon effects.

See [Migration 1.1 to 2.0](/reference/migration-1.1-to-2.0) for an actionable migration checklist.
