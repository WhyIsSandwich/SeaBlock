# Notable Technologies

This page highlights technology groups with the biggest planning impact in SeaBlock 2.0.

## Read this if...

- You need to choose between multiple tech paths.
- You are unsure what to research now vs defer.
- You want low-spoiler progression guidance.

## High-impact technology groups

### Early automation and fuel stability

These techs determine how quickly you stop hand-feeding and stabilize first automation loops.

### Filtration and ore control

These unlock better ore targeting and usually decide whether science progression bottlenecks persist.

### Smelting/metallurgy progression

These techs turn temporary plate production into scalable throughput.

### Logistics and scale tools

These techs shape how quickly you can move from local patches to base-wide structured systems.

## Decision table

| Situation | Prioritize this technology group | Why |
| --- | --- | --- |
| Frequent power resets | Early fuel stability | Base reliability improves immediately |
| One metal blocks science | Filtration/ore control | Unlocks targeted production |
| Plates cannot keep up | Smelting/metallurgy | Highest throughput leverage |
| Expansion gets messy and slow | Logistics/scale tools | Lowers integration and refactor cost |
