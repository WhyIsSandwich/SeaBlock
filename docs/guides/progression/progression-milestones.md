# Progression Milestones

Use this as a practical progression map. The goal is to know "what unlocks what" so your next build has clear purpose.

## Read this if...

- You are unsure what to prioritize next.
- Your factory grows but science progression still stalls.
- You want low-spoiler milestones instead of full chain spoilers.

## Milestone chain

1. **Bootstrap:** wind, slag loop, first plates.
2. **Red science online:** basic automation and first stable fuel loop.
3. **Green science transition:** improved ore paths, broader metal set, circuit growth.
4. **Mid game systems:** chemistry, stronger fuels, logistics expansion.
5. **Late game foundations:** high-tier materials, large science throughput, stability over novelty.

## Readiness checks by milestone

| Milestone | Minimum readiness checks |
| --- | --- |
| Bootstrap -> Red | Reliable plate trickle, stable startup power, first science path planned |
| Red -> Green | Automated fuel loop, stable base metals, room for expansion |
| Green -> Mid | Secondary metals reliable, filtration/smelting choices stable, no chronic brownouts |
| Mid -> Late | Logistics strategy selected, power roadmap defined, key bottlenecks measurable |

## Decision table

| Situation | Recommended action | Why |
| --- | --- | --- |
| Multiple systems are weak at once | Fix one science blocker chain first | Restores momentum quickly |
| You are tempted to full-refactor early | Defer refactor until next milestone is secured | Reduces rebuild churn |
| Throughput is unstable everywhere | Pause expansion and stabilize inputs | New builds amplify instability |
| You cannot choose next unlock path | Pick the path that removes a current blocker, not future optimization | Better short feedback loop |

## Anti-overbuild guidance

- Build only what supports the next milestone.
- Defer polish until after the milestone is stable.
- Treat temporary builds as disposable infrastructure.
- If a build takes longer to perfect than the tech it unlocks, simplify it.

## Practical checks per milestone

- **Power:** sustained headroom under normal and burst loads.
- **Materials:** no single metal hard-capping all downstream chains.
- **Science:** enough throughput to keep research meaningful.
- **Land/logistics:** expansion path is available before it is urgently needed.

## 2.0 notes

- Recheck milestone timing against 2.0 changes before copying old progression advice.
- Module/beacon and chain updates can shift when a milestone becomes practical.
