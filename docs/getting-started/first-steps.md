# First Steps

This page is a practical first-session checklist for your first 30 minutes in Sea Block.

## Read this if...

- Your game starts correctly, but you are unsure what to do first.
- You want a stable early setup before scaling.
- You keep running out of fuel, space, or starter materials.

## First 30-minute checklist

1. **Check the suspicious rock**
   - Pull out all starter machines, wind turbines, and landfill.
2. **Place all starting wind turbines**
   - Treat this as your baseline power while everything else is hand-fed.
3. **Lay minimal landfill, then stop**
   - Expand only enough for starter processing lines.
4. **Set up starter ore loop**
   - Water -> electrolysis -> slag -> stone -> mineralized water -> crystallizer -> starter ores.
5. **Start algae production**
   - Build green algae production for early fuel chain foundation.
6. **Build first lab and start automation research**
   - Aim to move from hand-fed bottlenecks toward basic automation.

## Early deadlocks and immediate fixes

| Problem                    | Fast fix                                                                                | Why it works                             |
| -------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------- |
| Constant fuel starvation   | Prioritize algae/fiber flow before adding more machines, don't forget to handcraft fuel | Stable fuel beats unstable expansion     |
| No room for key machines   | Pause expansion plans and landfill only for current bottleneck                          | Landfill is expensive early              |
| Recipes seem missing       | Validate version/settings before redesigning base                                       | Many issues are config drift, not layout |
| Wrong map start conditions | Stop and verify scenario/map assumptions                                                | Continuing on wrong start wastes time    |

## Handoff goals before leaving this page

- You have repeatable iron/copper plate output.
- Algae is running and early fuel is no longer purely manual.
- A lab is active and first automation research has started.
