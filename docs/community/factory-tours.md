# Factory Tours

Curated tours are useful for design inspiration, especially for transitions and scale decisions.

## How to use this page

- Compare multiple layouts for the same milestone.
- Focus on interfaces and expansion strategy, not exact tile-perfect copying.
- Capture ideas that match your current constraints (space, UPS, logistics style).

## Suggested tour categories

- Starter base that cleanly reaches green science.
- Mid-game refactor from spaghetti to structured blocks.
- Late-game science and power scaling examples.
- Performance-conscious mega-factory layouts.

## Contribution format

When adding a tour, include:

1. Game/pack version context.
2. Approximate milestone reached.
3. One-paragraph design summary.
4. What worked, what failed, and what you would change.
